## Как установить

**Mac (Apple Silicon — M1/M2/M3/M4):** скачайте `PDF-masterskaya-…-mac-arm64.dmg`, откройте его и перетащите
«PDF-мастерская» на папку «Программы». При первом запуске macOS предупредит, что разработчик не проверен
Apple: откройте «Программы», нажмите на программу **правой кнопкой → «Открыть» → «Открыть»**
(или «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть»).

**Windows 10/11 (64-бит):** скачайте `PDF-masterskaya-…-windows-setup.exe` и запустите. Если Windows покажет
синее окно SmartScreen, нажмите **«Подробнее» → «Выполнить в любом случае»** (установщик не подписан
сертификатом). Права администратора не нужны. После установки программа появится в «Пуске» и в меню
«Открыть с помощью» для PDF. Сделать её основной для PDF: правый клик по PDF → «Открыть с помощью» →
«Выбрать другое приложение» → «PDF-мастерская» → «Всегда».

Подписи и печати у каждого свои: они хранятся на компьютере (Mac — `~/Library/Application Support/PDF-мастерская`,
Windows — `%APPDATA%\PDF-мастерская`) и в установщик не входят.
