## Что нового в 1.2

* Программа теперь называется **PDFMaster**. Подписи и печати из прежней версии переносятся
  сами, на Windows новая версия ставится поверх старой и убирает её ярлыки.
* Mac: красная кнопка закрывает окно, а не всю программу (как в других программах Mac);
  значок в Dock открывает окно снова, выход — ⌘Q.

## Как установить

**Mac (Apple Silicon — M1/M2/M3/M4):** скачайте `PDFMaster-mac.dmg`, откройте его и перетащите
«PDFMaster» на папку «Программы». При первом запуске macOS предупредит, что разработчик не проверен
Apple: откройте «Программы», нажмите на программу **правой кнопкой → «Открыть» → «Открыть»**
(или «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть»).

**Windows 10/11 (64-бит):** скачайте `PDFMaster-windows-setup.exe` и запустите. Если Windows покажет
синее окно SmartScreen, нажмите **«Подробнее» → «Выполнить в любом случае»** (установщик не подписан
сертификатом). Права администратора не нужны. После установки программа появится в «Пуске» и в меню
«Открыть с помощью» для PDF. Сделать её основной для PDF: правый клик по PDF → «Открыть с помощью» →
«Выбрать другое приложение» → «PDFMaster» → «Всегда».

Подписи и печати у каждого свои: они хранятся на компьютере (Mac — `~/Library/Application Support/PDFMaster`,
Windows — `%APPDATA%\PDFMaster`) и в установщик не входят.
