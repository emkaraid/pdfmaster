# PDF‑мастерская

Нативная программа для macOS (Apple Silicon) для просмотра и правки PDF вместо Acrobat Pro:
правка текста с настоящим удалением старого, листы, подписи и печати, сжатие.
Интерфейс на русском, работает офлайн — без аккаунтов, телеметрии и сетевых запросов.

## Установка и сборка

```bash
./build.sh                 # тесты + сборка + установка в /Applications
./build.sh --no-tests      # без автотестов
./build.sh --no-install    # только собрать в dist/
```

Нужен Python 3.12+ для arm64 (берётся python.org 3.14 или Homebrew из /opt/homebrew),
для тестов — `pdftotext` (`brew install poppler`). Скрипт сам создаёт `.venv` и ставит
зависимости из `requirements.txt`. Результат — `/Applications/PDF-мастерская.app`;
программа появляется в «Открыть с помощью» для PDF и картинок. Чтобы PDF открывались
двойным кликом: Finder → любой PDF → «Свойства» → «Открывать в программе» →
«PDF‑мастерская» → «Изменить всё…».

Запуск из исходников: `.venv/bin/python -m pdfmaster [файл.pdf …]`.

## Почему так устроено

* **Движок — PyMuPDF (MuPDF).** Быстрый рендер векторных чертежей, настоящий redaction
  (`apply_redactions`), вставка шрифтов и картинок, операции с листами, сжатие.
* **Интерфейс — PySide6 (Qt) в одном процессе Python + процессы‑исполнители.**
  MuPDF не отпускает GIL, поэтому рендер, предпросмотр правок, поиск и сохранение идут
  в 2–3 отдельных процессах (`multiprocessing`). Интерфейс не замирает даже на листах
  с сотнями тысяч линий. Вариант Tauri + Python‑сайдкар дал бы два рантайма и сложную
  сборку при той же работе на стороне Python; Qt проще собирается в один .app
  (PyInstaller) и даёт нативные меню, диалоги, жесты трекпада.
* **Модель без изменения исходника до сохранения.** Документ — это список листов
  (ссылки на исходные файлы + поворот) и объекты правки на листах. Отмена/возврат —
  снимки этого небольшого состояния, поэтому ⌘Z работает для всех действий,
  а «отменить всё» возвращает файл, побайтно совпадающий с исходным.
* **Что на экране, то и в файле.** Предпросмотр листа с правками — это тот же код
  `bake_page()`, что применяется при сохранении, выполненный на копии листа.

## Как работает правка текста

1. Строки берутся из текстового слоя MuPDF и режутся на сегменты по большим разрывам
   и по границам ячеек таблиц (вертикальные линии между символами).
2. Старые символы удаляются из потока содержимого по‑настоящему (redaction только
   текста: линии и картинки рядом не трогаются). После сохранения старого текста нет
   ни в копировании, ни в поиске, ни в `pdftotext`.
3. Новый текст пишется прямо в поток содержимого (`BT … TJ … ET`) с точными
   позициями глифов, тем же размером, цветом и под тем же углом (в т.ч. вертикальные
   надписи на чертежах). Правленая строка переписывается целиком в логическом порядке:
   неизменённые символы остаются на своих местах (растр не меняется), поэтому
   копирование и поиск дают одну цельную строку.
4. Шрифт: если во встроенном подмножестве шрифта документа есть все нужные символы
   (проверяется по `/ToUnicode`), используются **те же коды того же шрифта** — выглядит
   идентично. Иначе встраивается замена: сначала тот же шрифт по имени (из системы
   или из программы), затем похожий с кириллицей — Times New Roman → Times New Roman
   macOS / Liberation Serif, Arial → Arial / Liberation Sans, PT → PT Serif/Sans,
   GOST type A/B, ISOCPEUR → osifont (ГОСТ‑подобный, курсив ГОСТ — наклоном 15°).
   Шрифты замен при сохранении урезаются до используемых глифов, а таблица
   `/ToUnicode` пишется программой сама, чтобы копировался ровно введённый текст.

## Работа

* **Просмотр:** вкладки, миниатюры, ⌘+/⌘−, щипок на трекпаде, ⌘1 — по ширине,
  ⌘2 — лист целиком, ⌘0 — 100 %, ⌥⌘G — перейти к листу, ⌘F — поиск (⌘G/⇧⌘G).
* **Выбор:** протянуть по тексту — выделение, ⌘C — копировать, двойной клик — слово,
  ⌘A — весь текст листа; на пустом месте — «рука» (тянуть лист); подписи, печати
  и надписи двигаются мышью.
* **Править текст (⌘E):** навести на строку — подсветка, клик — правка на месте
  (курсор там, куда кликнули). Enter/Esc — готово. Если текст перестаёт помещаться до
  края колонки или ячейки таблицы (в т.ч. при вставке ⌘V), программа сама переходит
  к правке абзаца с переносом. Абзац определяется по геометрии (левый край, шаг
  строк, заполненность), выравнивание по ширине/центру — само. Справа: шрифт, размер,
  жирный, курсив, цвет, «Уместить в прежние строки» (кегль уменьшается до 70 %, чтобы
  абзац не наползал на текст ниже; если наползает — красное предупреждение),
  «Вернуть исходный текст». Вставка из буфера — только простым текстом.
* **Добавить текст (⌘T):** клик в любое место, многострочный (Enter — новая строка).
* **Удалить область:** рамкой; удаляются текст, картинки (пиксели) и целиком
  попавшие линии; по желанию закраска белым.
* **Листы — «Систематизировать» (⇧⌘P, кнопка «Листы»):** все листы крупной сеткой
  с форматом (A4, A3 альб., A3×4…), при наведении — повернуть/удалить, «+» между
  листами — вставить пустой лист или файл, перетаскивание, извлечение, разделение,
  размер миниатюр ползунком.
* **Листы в колонке слева:** перетаскивание миниатюр, ⌘/⇧‑клик — несколько листов, поворот (⌘R/⌘L),
  удаление (⌫ в колонке миниатюр), пустой лист, вставка PDF/JPG/PNG/HEIC
  (в т.ч. перетаскиванием из Finder в колонку миниатюр), извлечение, разделение по
  диапазонам или каждые N листов, «Файл → Объединить файлы…».
* **Подписи и печати (⌘K):** скан (JPG/PNG/HEIC/PDF) с удалением белого/серого фона
  (учитывает неравномерное освещение), предпросмотр до/после, ползунок порога,
  обрезка краёв; рисование подписи. Клик — поставить, перетаскивание, угол — размер
  с сохранением пропорций, верхний кружок — поворот (с прилипанием к 0/90/180/270°),
  «На все листы» / «На выбранные». Вставляется PNG с прозрачностью без потерь, одна
  копия картинки на все листы. Если у скана есть разрешение (dpi), печать встаёт
  в натуральную величину. Библиотека: `~/Library/Application Support/PDF-мастерская/`.
* **Линейка (⇧⌘M):** расстояние (с углом), ломаная, площадь (с периметром); привязка
  к концам линий; ⇧ — угол кратно 15°. Масштаб берётся из файла, если AutoCAD/nanoCAD
  записали видовые экраны (/VP /Measure, например план 1:500), либо выбирается 1:N,
  либо калибруется по отрезку известной длины. «Нанести в документ» — размерные
  линии с подписями в PDF.
* **Оптимизировать PDF (⌥⌘O):** как в Acrobat — аудит, что занимает место; пресеты
  «печать / стандарт / минимальный», своё разрешение и качество JPEG, перевод в
  оттенки серого, урезание шрифтов, удаление JavaScript, миниатюр, метаданных,
  вложений, комментариев, ссылок, невидимого текста, сглаживание форм, уплотнение
  структуры. Результат — в новый файл, с отчётом «было → стало».
* **Сохранение:** ⌘S — во временный файл рядом, проверка, `fsync`, атомарная замена;
  ⇧⌘S или кнопка «Сохранить как» — в новый файл, исходный не меняется. «Файл → Сжимать при сохранении»: бережно (200 dpi, JPEG 85)
  или средне (150 dpi, JPEG 75) + очистка мусора; сильнее — нарочно нет.
  Файлы с ограничениями «только чтение» без пароля открываются и правятся; при
  сохранении программа предупреждает и снимает ограничения. Пароль на открытие
  сохраняется. О подписанных ЭП документах предупреждает.

## Структура

```
pdfmaster/
  core/        — без Qt: модель, шрифты, извлечение строк, запекание правок,
                 сохранение, картинки/фон, библиотека, диапазоны листов
  render/      — процессы-исполнители и диспетчер очереди
  ui/          — окно, просмотр листов, миниатюры, панель свойств, диалоги, иконки
  resources/   — шрифты (OFL/LGPL), иконка, перевод Qt
packaging/     — spec для PyInstaller, рисование иконки, точка входа
tests/         — генератор тестовых PDF и автотесты (pytest)
prototype/     — первая версия в браузере (для истории)
build.sh
```

## Тесты

```bash
PATH=/opt/homebrew/bin:$PATH .venv/bin/python -m pytest -q tests
```

Тестовые файлы создаются в `tests/fixtures/` (`tests/make_fixtures.py`): акт с Times
New Roman и таблицей (шрифты Type0/Identity‑H, как у Word), акт из LibreOffice,
чертёж A3 на 32 000 линий с ГОСТ‑шрифтом и вертикальной надписью, листы с `/Rotate`
90/270, защищённый от изменений PDF, скан печати на сероватом фоне. Проверяется сам
файл (`pdftotext`, растровое сравнение, структура PDF), плюс интеграционные проверки
интерфейса (клик по строке, ввод, печать, листы, поиск) без показа окна.

## Ограничения

* Правка в пределах строки — надёжно; правка абзаца переносит текст заново и задаёт
  ему один стиль (жирные слова внутри абзаца станут обычными). Если новый абзац
  длиннее старого, нижние строки могут наползти на следующий текст.
* Текст, нарисованный линиями (SHX‑шрифты AutoCAD, «текст в кривых»), и сканы
  без текстового слоя как текст не правятся — только «Удалить область» +
  «Добавить текст».
* Шрифты Type3 и нестандартные кодировки CJK не переиспользуются (будет замена).
* Невидимый текстовый слой OCR поверх скана при правке станет видимым текстом.
* Цифровая подпись (ЭП) после изменений становится недействительной.
